# Down South Land Solutions

Static site for downsouthlandsolutions.com. 65 pages, no build step.

Deploy: Cloudflare Workers — build command NONE, deploy `npx wrangler deploy`, root `/`.

## URLs

Pages are stored flat (`forestry-mulching.html`) and served at the directory
URLs the site uses (`/forestry-mulching/`). `html_handling` in `wrangler.jsonc`
is set to `force-trailing-slash`, which does that mapping and redirects the
no-slash form so there is one canonical URL per page. Do not change it without
adding redirects first — every internal link, canonical tag and sitemap entry
uses the trailing-slash form.
